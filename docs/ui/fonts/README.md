# Fonts

`ComicNeue-Angular-Bold.ttf` is the font behind Roblox's `Enum.Font.Cartoon` and the FontFace `rbxasset://fonts/families/ComicNeueAngular.json`. The reference game uses this font for its HUD and panels.

- Source: copied from the local Roblox install (`%LOCALAPPDATA%\Roblox\Versions\<version>\content\fonts\`).
- Licence: Comic Neue is released under the SIL Open Font License 1.1, which allows bundling it with these docs.
- The mockup embeds it as a data URI, so it renders the same in any browser. In the game itself, use `Font.new("rbxasset://fonts/families/ComicNeueAngular.json", Enum.FontWeight.Bold)`, or `Enum.Font.Cartoon`.
