100 Miles to Earth's Core: 1:1 UI mockup

Every screen copies the reference game's layout, sizes and colours, measured from the 2560×1440 recording (see docs/research/reference-ui/), and swaps in our game's wording. Sizes are in container units, so each 16:9 frame scales exactly. Backgrounds are placeholders; icons are flat stand-ins for the final 2D paintings.
